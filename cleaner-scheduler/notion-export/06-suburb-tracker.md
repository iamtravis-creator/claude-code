# Suburb Tracker

> Track the status of every suburb: page live, GBP service area, booking form, first booking, and review count.
> Update whenever a new suburb page is published or a status changes.

---

## How to Generate a New Suburb Page

```bash
python scheduler.py suburb --suburb "South Yarra" > content/south-yarra.md
```

Review the output, add local detail, publish to your website, then update this tracker.
