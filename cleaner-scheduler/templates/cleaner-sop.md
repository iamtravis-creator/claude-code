## Room-by-Room Checklist

Complete rooms in this order. Do wet areas before dry. Do top-to-bottom within each room.

### Kitchen
- [ ] Wipe all bench tops and splashbacks
- [ ] Clean stovetop (remove grates if applicable)
- [ ] Clean outside of all appliances (microwave, toaster, kettle, fridge)
- [ ] Clean inside microwave
- [ ] (Deep/EOL) Clean inside oven — use oven cleaner, leave to soak then wipe
- [ ] (Deep/EOL) Clean inside fridge — remove shelves, wipe down, replace
- [ ] Wipe cupboard fronts
- [ ] Clean sink and tap
- [ ] Empty and reline bins
- [ ] Sweep and mop floor

### Bathroom(s) — repeat for each bathroom
- [ ] Scrub toilet (inside bowl, under rim, seat, lid, base)
- [ ] Clean basin and tap
- [ ] Clean shower/bath — scrub tiles, glass, and fixtures
- [ ] Wipe mirror and glass surfaces
- [ ] Wipe towel rails and toilet roll holder
- [ ] Sweep and mop floor
- [ ] Replace toilet roll if nearly empty (from client's supplies)

### Bedroom(s) — repeat for each
- [ ] Dust all surfaces (bedside tables, dressers, shelves)
- [ ] (Deep/EOL) Dust and wipe skirting boards
- [ ] (Deep/EOL) Wipe window sills
- [ ] Vacuum or mop floor (including under bed if accessible)
- [ ] (EOL) Strip and remove bedding if requested

### Living Areas
- [ ] Dust all surfaces, shelves, and ornaments
- [ ] Wipe down furniture fronts (TV unit, coffee table)
- [ ] Clean glass (windows, TV screen with appropriate cloth)
- [ ] (Deep/EOL) Wipe skirting boards and window sills
- [ ] Vacuum furniture if applicable
- [ ] Vacuum or mop floor

### Laundry
- [ ] Wipe down washer and dryer fronts
- [ ] Clean sink
- [ ] Sweep and mop floor

### Outdoor / Balcony (if in scope)
- [ ] Sweep balcony or outdoor area
- [ ] Wipe outdoor furniture if included

## QR Card Usage

1. **On arrival**: Scan the arrival QR code on your job card — this logs your start time
2. **After final walkthrough**: Scan the task-completion QR code
3. **Before leaving**: Scan the departure QR code — this logs your end time and triggers the client's thank-you email

Leave the QR feedback card on the client's kitchen bench or table.

## Exit Protocol

1. - [ ] Do a final walkthrough — check every room is done and nothing was missed
2. - [ ] Windows closed (unless client requested otherwise)
3. - [ ] All taps off
4. - [ ] All appliances off (oven, stove, heaters)
5. - [ ] All lights off
6. - [ ] Doors locked — return key to key safe or lockbox if applicable
7. - [ ] [BIN_INSTRUCTION — e.g. "Leave bin bags on the doorstep" or "Place in bin room, Level G"]
8. - [ ] Leave a brief handwritten or printed note for the client: "Your home has been cleaned by [YOUR NAME], Main10 Clean. Have a great day!"
9. - [ ] Scan departure QR code
